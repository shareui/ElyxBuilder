# ElyxBuilder

CLI-инструмент для сборки Elyx-плагинов.

## Установка

```
pip install ElyxBuilder
```

## Требования

- Python >= 3.10
- Python 3.11 / 3.12 / 3.13 / 3.14 — нужен только для компиляции `.pyc` (версия задаётся через `compilePythonVer` в `elyxbuilder/config.json`)
- pyzipper — нужен только для шифрования архивов
